# Patient-Tracker-AI

Patient Tracker AI is an intelligent healthcare operations platform designed to help hospitals and clinical teams ensure that every patient is seen on time and receives appropriate care attention. The application combines real-time patient monitoring, AI-driven acuity scoring, and workflow automation to improve patient visibility, communication, and clinical efficiency.

Built with React and Tailwind CSS, the platform features a live census dashboard that tracks patient status across units in real time. The system uses AI-powered acuity analysis to identify high-risk patients, prioritize urgent cases, and generate escalation alerts for delayed rounding or missed care actions.

## Features

* **Live Census Dashboard**
  Monitor all active patients in real time with status indicators and room tracking.

* **AI Acuity Scoring**
  Analyze patient risk levels using AI-based prioritization to identify critical or deteriorating patients.

* **Rounding Timers & Alerts**
  Automatically track patient rounding intervals and notify healthcare staff when patients are overdue to be seen.

* **Escalation System**
  Trigger alerts for urgent situations, unseen patients, or high-risk conditions requiring immediate intervention.

* **Color-Coded Patient Status**

  * 🟢 Green — Patient has been seen
  * 🟡 Amber — Patient rounding overdue
  * 🔴 Red — Patient not seen / urgent attention required

* **Workflow Optimization**
  Streamline communication between doctors, nurses, and hospital departments.

* **Responsive UI**
  Modern frontend built with React and Tailwind CSS for fast, scalable, and responsive healthcare workflows.

## Tech Stack

* React
* Tailwind CSS
* JavaScript
* AI/ML Logic (planned or integrated)
* Real-Time Dashboard Architecture

## Vision

The goal of Patient Tracker AI is to reduce missed patient care opportunities, improve hospital workflow efficiency, and support healthcare teams with intelligent real-time decision-making tools.
